# 微信本地查询

通过百积木本地微信应用已登记的查询方法读取会话、联系人和历史消息。用毫秒 Unix 时间戳传递时间范围。

如果方法报告采集器不可用，查看本地微信应用状态页，确认独立采集器已启动且已配对。
