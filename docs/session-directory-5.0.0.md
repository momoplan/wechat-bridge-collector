# 微信本地连接器 5.0.0 会话排序

2026-11-19 用户确认从客户端本地应用 4.2.0 升到 5.0.0（MAJOR），让渠道的 `listSessions` 按微信会话表中的最后活动时间混排群聊和私聊。活动时间相同时按原生会话 ID 升序。仍在通讯录但尚无会话时间的群排在有活动记录的会话之后。

游标记录最后活动时间和原生会话 ID，并绑定到同一微信账号和关键词。目录每次读取当前设备数据。翻页期间有新活动的会话可能移动到已读页面的前方，刷新第一页可看到最新顺序。旧版只包含会话 ID 的游标升级后失效，调用者须从第一页开始。响应继续使用 `items[].sessionKey`、`items[].title` 和 `nextCursor`。
