# 微信本地连接器 4.2.0 会话目录

2026-11-19 用户确认客户端本地应用从 4.1.1 升到 4.2.0（MINOR），新增只读方法 `listSessionDirectory`，供桌面个人微信客服渠道的 `listSessions` 使用。

微信本地连接器从当前账号的会话表和联系人数据读取可见会话与仍可访问的群聊。会话项使用与消息事件相同的原生 ID 作为 `sessionKey`。现有名称解析提供 `title`，源数据缺少可展示名称时省略这一可选字段。目录只读取会话和联系人数据。

请求的 `limit` 为 1 到 200。可选 `keyword` 匹配名称或原生 ID，`cursor` 来自同一账号、同一关键词的上一页。响应包含 `items` 和 `nextCursor`，末页的 `nextCursor` 为 null。

已部署的渠道后端 5.2.0 使用上述方法及返回字段。验收设备需要通过百积木客户端升级到 4.2.0，并允许工作区调用该只读方法。用绑定设备在正式 Runtime 调用 `listSessions`，核对群聊 `sessionKey` 与 `items[].title`，并用实际回包检验搜索和分页。
